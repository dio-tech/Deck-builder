# Deck-builder
In order to build a deck you need various number of wooden boards with different sizes and beams underneed to support them but what about the waste that it is produced? Can we make it more efficient in a way that reduces the price and what goeas away? Well, with this program you can find the best boards to use according to your stock and the ideal position to place them. It also tells you the best position to place the support beams given a minimum gap between the change of wooden board. This program not only tells you this but it also tells you the quantity of each board you will need, the price you will pay in total, the waste of wood and a visual representation of the deck. The program it's made for astetics so the pattern will not seem so regular. Try it yourself.
